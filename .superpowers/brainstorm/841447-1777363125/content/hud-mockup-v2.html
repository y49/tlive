3 种交互类型一览

  • 单选 (multiSelect: false) — 点按钮即 resolve / 也可发数字或 label 文本透传 / 也可点"自己输入"转自由文本
  • 多选 (multiSelect: true) — 按钮 toggle ⬜/✅ / 底部"确认"按钮提交 / 也可发"1,3"或"甜,辣"逗号分隔文本透传
  • 自定义输入 — 用户点"✏️ 自己输入" → buttons 灰掉,bot 提示 → 用户下条 plain text 自动作为答案 resolve

所有 3 种都通过 inline-dispatcher 的 ask-relay 逻辑统一处理,plaintext 路径在 daemon side 解析。
