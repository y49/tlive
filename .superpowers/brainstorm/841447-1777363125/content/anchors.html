✅ 保留(6 个核心 anchor)

1. Session header(pinned)
📌 tlive · 8cdfcfb · $0.12 · opus-4-6

每个 session 一个,pinned,显示 alias + cost + model + cache 状态。
触发:session 创建时 send pinning,turn_end 时 edit refresh

2. Reaction on 用户消息
测试 AskUserQuestion 🤔

👀 daemon 收到 → 🤔 处理中 → 👌 done / 💔 fail。

3. Activity sticky(1/turn, edit-in-place)
🔧 Bash · 2.1s
✅ ToolSearch · 0.3s

显示当前 tool / 已完成 tool 列表 / thinking 状态。
关键:1 turn = 1 message,所有状态变化都 edit_in_place

4. Agent message + footer
README 是项目说明文档,主要包含项目简介、安装步骤...
📊 1.2K tok · $0.03 · 4.2s

Claude 文本回复 + 一行 stat footer。

5. Permission card
🔒 Bash · low-risk
$ ls /tmp

SDK 要权限时弹出。AskUserQuestion 是特化 case(显示选项 + 数字回复也接受)

6. Attachment(按需)
📎 output.png · 245 KB

Agent 用 Write 输出文件时才出现。99% 的 turn 不会触发,几乎不打扰

❌ 砍掉 / 合并(7 个)

合并到 Activity sticky:
  • todo-sticky — Claude 写 todo list 时,作为 sticky 内的一个 section,不单开消息
  • parallel-tools / subagent-nested — 内嵌进 sticky 的 tool 列表,不单独 renderer
  • cache-badge — 显示在 header 里(`📌 ... · 🔥 cache 5min`),不单独消息
  • queue-hint — 如果用户连发,在 sticky 内加一行"⏭ 排队 1",不单独 renderer
独立成 anchor 但只在罕见 case 用:
  • elicitation-form — 跟 permission-card 用同一 renderer 类(它们结构几乎一样,reuse)
